# PathFinder Project Rules

- Tutor V3 in `docs/product/PathFinder_Project_Documentation.md` is the source of truth.
- Preserve FR-01–FR-24 and TR-01–TR-18 exactly.
- Follow the binding stack in tutor V3; do not substitute or add infrastructure.
- Eligibility is deterministic; AI cannot decide or override it.
- Eligibility, relevance and readiness remain separate.
- Unknown is not pass; ambiguity requires review.
- Opportunity facts must be grounded in official sources and verification evidence.
- User applications occur on official provider channels.
- Protect profile, assessment and application data with server-side authorization.
- Keep secrets server-side and out of Git.
- Keep domain logic in feature modules.
- Inspect and preserve existing repository work before modifying files.
- Specification and schema review precede migrations and implementation.
- Use small traceable tasks and evidence-based reports.
